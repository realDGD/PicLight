# Agent Note：第二批使用流程

Status: proposed

## 问题

用户已选择按本地功能清单的第二批推进。当前 main 已合入设置、目录授权、三槽动画与 CLT 打包，旧功能分支已归档；新功能需从当前基线实施，避免再把历史来源当作正在使用的版本。

## 建议

完整范围、默认值建议、行为优先级、异常与生命周期要求统一写在[第二批设计](../../../docs/superpowers/specs/2026-10-25-batch-two-workflows-design.md)。采用原生 AppKit 与系统 VisionKit / Vision 接口，复用既有目录、视口与缩略图模型。文件夹授权已实现，本批保留其回归；桌面贴图在第三批。

## 取舍与约束

系统最近文档与系统选字交互减少应用维护的持久化和输入模型；在不支持实况文本覆盖层的设备保留文字识别与复制。新能力不触发无界原图解码或整段动画缓存；后台工作按文件版本、请求与窗口生命周期拒绝旧结果。

继续遵守不弹窗、不生成测试 App、暂不做实际使用验收与不跑完整 Swift 测试的要求。真实授权、默认应用关联和应用安装不由设计文档自动触发。

## 当前证据

本次已核对清单、当前源码、Apple 文档与本机 CLT SDK 的相关接口；目前只形成设计，没有修改产品代码，也没有新增功能通过声明。设计确认与实施后，应更新状态、实际决定及定向验证结果；本记录在此之前保持 proposed。
