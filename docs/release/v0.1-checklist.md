- **PASS** — verified automatically in this repository, with the command recorded.
- **MANUAL-PENDING** — needs a human at a display; never marked PASS until someone does it.
- **FAIL** — a check that ran and did not pass. (Currently none.)

Verification record: `docs/release/v0.1-rc1-automated-verification.md`.
Artifact verification: `scripts/verify-release.sh`.

automated result above should be read as covering them.

| # | Item | Why it cannot be automated here | What to do |

## 4. Tagging policy

`v0.1.0-rc1` may be tagged while §3 is pending, because a release candidate exists
precisely to gather that manual verification. `v0.1.0` must not be tagged until
every row in §3 has been performed and recorded:

```bash
# only after §3 is complete
git tag -a v0.1.0 -m "PicViewMac v0.1.0"
```

## 5. Explicitly out of v0.1 scope

No slideshow, permanent editing, rename/move, clipboard editing, always-on-top,
custom tabs, updater, telemetry, cloud/network features, RAW/pro formats,
HDR/EDR, J3 customizable toolbar, persistent disk thumbnail cache, or
signed/notarized distribution. HEIC/HEIF remains outside the v0.1 claim.
