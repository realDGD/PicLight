## 状态与证据规则

- **已验证**：必须注明执行日期、源码或产物版本、检查范围；只证明该范围。
- **待验收**：当前行为需要实际使用或呈现测量，尚未执行。
- **未运行**：当前基线没有这项检查的结果。
- **历史记录**：只说明旧版本，不能当作当前版本通过。
- **失败**：检查实际执行且失败，保留失败与后续修正记录。

当前源码、构建方式和测试选择分别见[开发指南](../development.md)、[验证指南](../testing.md)。旧 [RC1 自动验证报告](v0.1-rc1-automated-verification.md)保留历史内容；其中的测试数量、App/DMG、验收运行器成绩不再作为本清单的当前门槛。

## 3. 暂缓的实际使用验收

以下全部为 **待验收**，本次不执行。M1–M5 保留编号供窗口兼容说明引用。每次验收应记录应用 revision、设备 / 系统、样本、操作及观察结果；失败时记录可复现条件。

| 编号 | 场景 | 需要观察的结果 |
| --- | --- | --- |
| M1 | Mission Control，1 / 2 / 3 个查看器 | 各查看器保持独立的原生窗口 |
| M2 | Stage Manager | 加入、移出和恢复窗口行为正常 |
| M3 | 原生平铺、拖动、缩放 | 系统操作可用，画布没有额外跳动 |
| M4 | 实际安装的第三方窗口管理器 | 在指定工具中移动、吸附、缩放；记录工具和版本 |
| M5 | 原生全屏与退出 | Space 转换、菜单栏、窗口数量与沉浸模式状态符合当前约定 |
| M6 | 最终设置窗口 | 六个顶层页、看图六分类、快捷键表和目录列表可操作；切页无伸缩、标签移动或重复边框 |
| M7 | 真实目录权限 | Downloads 前置面板默认用户主目录；授权后自动继续原操作；取消、重开与书签失效恢复符合说明 |
| M8 | GIF / APNG / 动画 WebP 持续播放 | 使用先前样本和不同尺寸、帧时长、有限循环样本；分别记录源循环时长、实际循环耗时、卡顿、丢帧、CPU 与进程 / GPU 内存趋势；包含独立封面 APNG、切图和关闭 |
| M9 | 标题栏、工具坞、导航覆盖层 | 各显隐策略下 Fit 和手动缩放的画布、中心、输入路由稳定；隐藏视图不拦截事件 |
| M10 | 缩略图栏、网格、鸟瞰图和信息卡 | 显式布局变化符合设置，选择与视口恢复，Retina 预览和视口边框清晰 |
| M11 | 滚轮、物理捏合和滑动 | 覆盖控件上的输入到达画布，文本编辑保留焦点；不把惯性滑动误当翻页 |
| M12 | 启动、Dock 重开、空窗口和多窗口 | 正常显示欢迎状态或恢复窗口，不累积重复窗口，不闪现图片专属控件 |
| M13 | 浅色 / 深色、辅助功能、图标 | 在对应系统版本观察材质与图标；不从静态图标导出推断系统实时显示 |
| M14 | 目录变化、删除确认与失败恢复 | 在明确安排的临时样本上检查选择、错误提示、取消和同路径替换；不擅自删除真实照片 |
| M15 | 系统默认应用关联 | 只有用户明确点击应用后写入；实际系统写入需单独安排，注入后端测试不等于系统验证 |
| M16 | 离线首次使用、Gatekeeper 与其他 macOS / GPU | 按实际交付渠道和设备分别记录；本机 headless 检查不能证明所有设备 |

M8 的性能测量需区分目标时间轴、就绪帧和实际呈现。单元测试中的时间计算、离屏绘制和 RSS 单点都不能单独证明屏幕流畅且内存稳定。需要 Instruments 或其他测量时另行安排；不自动启动窗口。
