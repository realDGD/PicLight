## Requires a human before tagging

1. **Window-manager matrix** — Mission Control, tiling, Stage Manager, native
   Full Screen, and third-party managers. See
   `docs/window-manager-compatibility.md`. Not executed here (no display access).
2. **Visual acceptance** — chrome fading, hover timing feel, minimap
   appearance, Light/Dark materials, Reduce Transparency and Reduce Motion at
   the system level. The runner verifies the *behavior*; nobody has looked at it.
3. **Instruments profile** of a large JPEG/TIFF — see
   `docs/performance-v0.1.md` (peak memory not empirically recorded).
4. **DMG install on a clean local user account** — Task 23 Step 6.
5. **Offline launch** — the app has no network code paths or dependencies, but a
   clean-room offline launch has not been performed.

## Tagging

Tag only after the five human items above are complete:

```bash
git tag -a v0.1.0 -m "PicViewMac v0.1.0"
```

## Explicitly out of v0.1 scope

No slideshow, permanent editing, rename/move, clipboard editing, always-on-top,
custom tabs, updater, telemetry, cloud/network features, RAW/pro formats,
HDR/EDR, J3 customizable toolbar, persistent disk thumbnail cache, or
signed/notarized distribution. HEIC/HEIF stays out of the release claim.
