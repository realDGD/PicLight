# B 批：文件夹访问管理

用户已要求实现本地功能清单 3.5.1 的完整文件夹流程。沿用“先实现，再集中做相关测试”的顺序，在当前功能分支继续。

## 范围和验收

- 设置 → 文件与缓存打开独立的“文件夹授权”管理窗口；目录列表支持添加、移除、重新选择、刷新和可访问/位置不可用/需要重新选择状态。
- 添加通过原生选择面板，取消不改变记录；检查实际目录读取后才保存，按规范化路径去重。普通书签用于当前独立应用，安全作用域书签按实际沙盒模式选择；启动恢复、过期更新及开始/结束配对。
- 读取父目录失败时仍可显示明确打开的单张文件；错误不能伪装为空目录。看图和网格均有错误与手动恢复入口；重新选择正确目录后重试原操作并保留明确打开目标。
- “读取失败时提示授权”只控制自动引导；关闭后仍有错误和手动入口。同一持续失败不重复弹窗，旧目录的结果和恢复动作不能覆盖新目录。
- 移除仅清理应用的记录与对应访问资源；不删除文件，不撤销系统完全磁盘访问。单独提供系统权限指南，不声称应用能自行授予权限。
- 不改变原生窗口、画布或六个设置页的尺寸；不实现递归图片浏览或自动重开上次目录。

## 实施

1. FolderAccessStore：记录、书签后端、读取检查、恢复、资源生命周期与通知。
2. FolderAccessViewController / FolderAccessPanel：管理界面、面板取消和重新选择、权限指南。
3. ViewerViewController：共用扫描错误处理、单图保留、错误覆盖层、恢复与异步代际；AppDelegate 接入目录保存、启动与退出。
4. 完成后增加少量关键回归，集中检查记录恢复、资源平衡、空目录/权限错误、重试及旧请求防护；验证实际应用包和管理入口。
