### B 批：文件夹访问管理

`49bc39a` 实现本地功能清单第 3.5.1 节。入口为 **设置 → 看图 → 打开** 的内联授权列表（改版前为 设置 → 文件与缓存），或 **文件 → 文件夹授权…**。

- 原生管理窗口支持添加、移除、重新选择、刷新状态和浏览目录；取消面板不改变记录。
- 检查真实目录读取后保存书签，按规范化路径去重；启动恢复记录，更新过期书签和移动后的路径。
- 列表区分可访问、位置不可用和需要重新选择，并显示具体原因。
- 父目录扫描失败时仍尝试显示明确打开的单张图片。看图与网格都保留错误和“选择文件夹… / 重试”入口。
- 重新选择原目录或上级目录后重试原操作并保留目标图片；上级目录恢复访问时同步子目录记录状态。
- 自动授权提示可以关闭，手动入口仍保留；同一持续失败不重复弹窗。目录切换、记录移除和窗口关闭会使迟到结果失效。
- 移除记录不删除文件，也不撤销 macOS 完全磁盘访问。系统权限指南独立提供。

用户行为见[文件夹访问说明](<../folder-access.md>)，实现取舍见[B 批 Agent note](<../../.agents/notes/implemented/2026-10-13-folder-access.md>)，验收范围见[B 批计划](<../superpowers/plans/2026-10-13-folder-access.md>)。
