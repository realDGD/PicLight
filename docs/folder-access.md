# 文件夹授权与访问记录

在 **设置 → 文件与缓存 → 管理文件夹授权…**，或 **文件 → 文件夹授权…** 打开管理窗口。

- **添加…**：使用 macOS 原生面板选择文件夹，确认可以读取后保存。取消不改变记录，同一路径只保留一条。
- **浏览文件夹**：浏览选中目录中的图片，不递归合并子目录。
- **刷新状态**：重新解析保存的书签并检查目录。状态显示“可访问”“位置不可用”或“需要重新选择”；具体原因显示在列表下方。
- **重新选择…**：恢复失效的记录，也可更新已移动的目录。正在浏览旧目录的窗口随记录更新，并尽量保留原来的图片。
- **移除记录**：清除 PicLight 保存的记录。不会删除文件，也不会撤销 macOS 的完全磁盘访问。

记录在下次启动时恢复。当前独立应用没有启用 App Sandbox，保存普通书签并检查实际读取结果；运行在沙盒模式时使用安全作用域书签。保存路径、保存书签和系统权限是不同的状态，“可访问”表示当前目录读取检查成功。

打开图片后，如果父文件夹不能读取，PicLight 会继续尝试显示这张图片，同时保留文件夹错误和 **选择文件夹… / 重试** 入口。选择原目录或它的上级目录后，重试原来的打开操作；不会因为扫描失败而跳到另一张图片。目录位置不存在时，可以重新选择其他位置。

**读取失败时提示授权** 控制是否自动弹出权限引导。关闭后，错误和手动恢复按钮仍然保留。同一持续失败不会每次翻页都弹窗。看图和网格模式使用同一个恢复入口。

**系统权限指南…** 说明如何打开“系统设置 → 隐私与安全性 → 完全磁盘访问”，由用户添加正在使用的 PicLight.app，完全退出后重新打开。应用不会自动授予权限，也不把目录记录显示成完全磁盘访问的开关。磁盘未挂载、文件已移走和文件自身权限不足需要分别处理。
